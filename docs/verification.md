- `npm run verify`：四套系統 API 與共用路由的 JSON 結果一致；CORS、錯誤參數、伺服器 HTML 及 JSON-LD 正常。
- Headless Chromium：多語及座標搜尋、地圖選站與路徑 highlight、旅程縮放與站名完整顯示、複製文字、三語切換、Preview 主題及手機排版通過；沒有未處理的頁面 JavaScript 錯誤。
- Editor：修改站名、實際滑鼠拖曳車站與轉折點、右鍵刪除轉折點、保留原始遊戲座標與里程、JSON 載入／儲存、無效 JSON 保護，以及試算後返回編輯器的資料保留通過。新增區間在修改路線與車站後推算方向／里程、保留手動方向覆寫、切換轉乘時里程歸零，也已通過瀏覽器操作驗證。
- Editor 操作回歸：按下車站（含略微拖動）及站名會同步切換左側設定；symbol 型態／方向能修改、復原及重做。中英文站名拖曳保留抓取偏移並切換八方向，且不更動車站位置；縮放時站名與站點的畫面間距不變。側欄及 Shift 點選都僅新增一個轉折點；實際按鈕操作放大至超過 64 倍，編輯器上限為 128 倍。台北地圖只顯示實體路線及支線的圖例。
- 未下載保護：儲存到文字框仍提醒、切換系統的取消／接受、透過連結離開的原生 beforeunload、未提交草稿關閉視窗後取消、下載 JSON 後清除提醒，以及後續修改重新提醒通過。
- 復原紀錄：核心測試驗證混合移動方式的分組、不同目標／屬性分組、重做分支清除、100 組上限、零變更組別移除、車站刪除的連接／別名／票價與清單順序還原、無效 before／after、非法動作／資料鍵及無效歷史鏈。每次載入、回放與匯出前都驗證可行性，失敗保留原資料；損壞 JSON 保留可驗證的連續後段、無法回放的未來紀錄與外層結構捨棄、回放失敗後正常新增紀錄及替換重做分支亦通過。

## 容量與範圍

瀏覽器及附屬測試快取約 326 MiB。整個新版目錄約 566 MiB，包含約 60 MiB 的 `node_modules/`、175 MiB 的 `.npm-cache/` 以及建置與截圖；這些開發產物不需要隨正式網站發布。

路由比對包含所有支援選項的完整邊集合，站對則採固定抽樣，未宣稱窮舉全部站對。測試涵蓋本機正式模式，尚未部署外部主機，也未建置 Docker image。
