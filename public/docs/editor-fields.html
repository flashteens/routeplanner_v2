條件式時間 · variants (zh)

JSON 陣列：每項以 when 指定馬匹速度或快速列車設定，並以 timeSec 指定基本時間（搭乘含出發站停靠，不含抵達後停靠）。只採第一個符合項目；無符合項目時整條路段停用。正反向都套用本路段的迷路旅客延誤設定。填 [] 可移除條件，改用基本時間。完整欄位與範例請見文件。

  • when 只接受 horseSpeedClass（字串代碼陣列）與 enableExpressCarts（數字陣列）。同一陣列任一值符合，不同條件須同時符合；省略的條件不限制。when: {} 匹配所有選項，可能遮蔽後續項目。
  • timeSec 必填且為非負有限秒數。搭乘包含出發站停靠與行車，不含抵達後停靠；步行與轉乘不加停靠。reverseTimeSec 可省略，沿用連接既有反向時間，不自動改成項目的 timeSec。
  • delayWhenUnfamiliar 設定在連接本身，不寫在 variants 裡。啟用後，正反向基本秒數皆套用「基本秒數 × (0.2 × 係數 + 0.8) + 5/3 × (係數 − 1)」。20 秒在係數 1／4／7 為 20／37／54 秒，未啟用則固定為基本秒數。
  • 僅採第一個符合項目；無符合項目時整個連接停用。條件式時間不改變里程、票價或方向。編輯器填 [] 會移除 variants 並使用基本時間；直接在 JSON 保留 variants: [] 則停用連接。
  • 舊儲存斜率可讀取，但匯出後改用連接的布林延誤設定與共用公式。修改基本時間不會自動更新既有條件式基本時間，需分別調整。
[
  {
    "when": {
      "enableExpressCarts": [
        1,
        2,
        3
      ]
    },
    "timeSec": 52.5,
    "reverseTimeSec": 52.5
  }
]

官方票價設定（JSON） · fares (zh)

此 JSON 物件包含完整票價設定，而不只是票價表。type 選擇免費、區間加總或起訖票價；currency 為貨幣，matrix 為起訖站票價，externalTransfers 為站外轉乘規則。完整欄位與範例請見文件。

  • type: free 為免費；additive 加總路段 metrics.price；origin-destination 使用 matrix[出發站ID][目的站ID]，不是各路段票價相加。currency 可為字串或 null；顯示票價另由 UI 設定控制。
  • matrix 為以 canonical 車站 ID 為索引的巢狀物件，票價須為非負有限數，正反向分別填寫。起訖相同票價為 0；缺少起訖組合時票價為未知。
  • externalTransfers 是可選陣列，每項 from、to 指定站外轉乘站，maxSeconds 指定優惠轉乘時間上限。超時會分段計算 origin-destination 票價，規則匹配雙向。
  • ticketType、source、download、retrieved、transferSource 可保留票種與來源資訊；這些不是時間條件。上例只示範結構，站號 A、B 必須在您的地圖中存在，maxSeconds 並非步行所需時間。
{
  "type": "origin-destination",
  "currency": "TWD",
  "matrix": {
    "A": {
      "A": 0,
      "B": 20
    },
    "B": {
      "A": 20,
      "B": 0
    }
  },
  "externalTransfers": [
    {
      "from": "A",
      "to": "B",
      "maxSeconds": 1200
    }
  ]
}

其他路線選項 · options (zh)

此 JSON 物件設定可選路線偏好、轉乘係數、馬匹速度及快速列車等級，defaults 為預設選項。comparators 決定各偏好的比較順序與權重；預設值必須列在對應的可選清單中。完整欄位與範例請見文件。

  • defaults 指定預設 criteria、transferCoef；有馬匹／快速列車清單時，另設 horseSpeedClass、enableExpressCarts。criteria 是查詢頁面列出的路線偏好代碼，transferCoefficients 是可選係數（有限數且至少 1）。預設值必須屬於對應清單。
  • horseSpeeds 可選，內容為馬匹代碼字串；expressLevels 可選，內容為快速列車等級數字。搭配 variants.when 使用，單純新增選項不會自動產生路段或時間。
  • comparators 是以偏好代碼為索引的物件，每個值為權重物件的陣列。每個權重物件先計算加權總分，依陣列順序比較：前一項相同才比較下一項，較小者優先。
  • 權重鍵僅接受 timeSec、transfers、transferTimeSec、stops。權重為非負有限數；每組至少有一個正權重。criteria 中每個代碼都需要對應 comparator。示例先比較時間，時間相同再比較轉乘次數。
{
  "defaults": {
    "criteria": "time",
    "transferCoef": 1
  },
  "criteria": [
    "time",
    "transfers"
  ],
  "transferCoefficients": [
    1,
    4,
    7
  ],
  "comparators": {
    "time": [
      {
        "timeSec": 1
      },
      {
        "transfers": 1
      }
    ],
    "transfers": [
      {
        "transfers": 1
      },
      {
        "timeSec": 1
      }
    ]
  }
}

Conditional timings · variants (en)

A JSON array: when matches horse speed or express-cart settings; timeSec specifies base time (rides include departure dwell, not arrival dwell). Only the first match is used; no match disables the connection. Both directions use the connection’s unfamiliar-traveler setting. Enter [] to remove conditions and use base timing. See the documentation for fields and examples.

  • when accepts horseSpeedClass (string-code arrays) and enableExpressCarts (number arrays). Values within an array are OR; conditions are AND. Omitted conditions are unrestricted; when: {} matches everything and can mask later entries.
  • timeSec is required, finite and nonnegative. Rides include departure dwell and travel, not arrival dwell. Walks and transfers exclude train dwell. Optional reverseTimeSec inherits the connection’s base reverse time, not this entry’s forward time.
  • delayWhenUnfamiliar belongs to the connection, not to variants. When enabled, both directions use: base seconds × (0.2 × coefficient + 0.8) + 5/3 × (coefficient − 1). A 20-second base gives 20/37/54 seconds at coefficients 1/4/7. Disabled means fixed base time.
  • Only the first match is used. No match disables the whole connection. Variants do not change distance, fare or direction. [] in the editor removes variants; explicit variants: [] in network JSON disables the connection.
  • Legacy stored slopes remain readable, but export converts them to the connection’s boolean setting and shared formula. Editing base timing does not update existing variant base times.
[
  {
    "when": {
      "enableExpressCarts": [
        1,
        2,
        3
      ]
    },
    "timeSec": 52.5,
    "reverseTimeSec": 52.5
  }
]

Official fare configuration (JSON) · fares (en)

This JSON object contains the entire fare configuration, not just the fare matrix. type selects free, additive or origin-destination fares; currency is the currency, matrix holds origin/destination fares, and externalTransfers defines out-of-station transfer rules. See the documentation for fields and examples.

  • type: free means no fare; additive sums edge metrics.price; origin-destination uses matrix[originID][destinationID], rather than summing edge fares. currency is a string or null. Fare display is controlled separately by UI settings.
  • matrix is a nested object keyed by canonical station IDs, with finite nonnegative fares. Provide each direction separately. Same-station fares are zero; missing OD pairs produce an unknown fare.
  • Optional externalTransfers entries specify from, to and maxSeconds for out-of-station transfer discounts. When the time limit is exceeded, origin-destination fares are calculated separately for each portion. Each rule applies in both directions.
  • Optional ticketType, source, download, retrieved and transferSource retain ticket/source metadata. The example illustrates structure only: stations A and B must exist in your map. maxSeconds is a discount limit, not walking time.
{
  "type": "origin-destination",
  "currency": "TWD",
  "matrix": {
    "A": {
      "A": 0,
      "B": 20
    },
    "B": {
      "A": 20,
      "B": 0
    }
  },
  "externalTransfers": [
    {
      "from": "A",
      "to": "B",
      "maxSeconds": 1200
    }
  ]
}

Journey options · options (en)

This JSON object defines routing preferences, transfer coefficients, horse speeds and express-cart levels. defaults sets initial choices. comparators specifies comparison order and weights for each preference. Defaults must appear in their corresponding allowed lists. See the documentation for fields and examples.

  • defaults sets criteria and transferCoef, plus horseSpeedClass and enableExpressCarts when their lists exist. criteria lists routing preference codes; transferCoefficients lists finite allowed coefficients of at least 1. Defaults must belong to their allowed lists.
  • Optional horseSpeeds contains string codes; optional expressLevels contains numeric levels. These work with variants.when. Adding an option alone does not generate connections or timing.
  • comparators maps preference codes to arrays of weight objects. Each object produces a weighted sum; sums are compared in array order, with later sums breaking ties. Lower scores win.
  • Allowed weight keys are timeSec, transfers, transferTimeSec and stops. Weights must be finite and nonnegative; each object needs a positive weight. Every listed preference needs a comparator. The example prioritizes time, then transfers when times tie.
{
  "defaults": {
    "criteria": "time",
    "transferCoef": 1
  },
  "criteria": [
    "time",
    "transfers"
  ],
  "transferCoefficients": [
    1,
    4,
    7
  ],
  "comparators": {
    "time": [
      {
        "timeSec": 1
      },
      {
        "transfers": 1
      }
    ],
    "transfers": [
      {
        "transfers": 1
      },
      {
        "timeSec": 1
      }
    ]
  }
}

条件付き所要時間 · variants (ja)

JSON 配列です。when で馬の速度や快速トロッコの設定を指定し、timeSec で基本時間を指定します（乗車は出発駅の停車を含み、到着後の停車を除きます）。最初の一致のみを使い、一致しなければ接続が無効になります。両方向に接続の習熟度設定を適用します。[] で条件を削除します。詳細と例は説明文書をご覧ください。

  • when は horseSpeedClass（文字列配列）と enableExpressCarts（数値配列）に対応します。配列内はいずれか一致、異なる条件はすべて一致が必要です。省略条件は制限せず、when: {} はすべてに一致します。
  • timeSec は必須の非負有限秒数です。乗車は出発駅の停車と走行を含み、到着後の停車を除きます。徒歩・乗換には列車の停車を加えません。reverseTimeSec は省略時に接続の基本逆方向時間を使い、この項目の正方向時間には変更しません。
  • delayWhenUnfamiliar は接続本体に設定します。有効時、両方向の基本時間に「基本秒数×（0.2×係数＋0.8）＋5/3×（係数−1）」を適用します。基本 20 秒で係数 1／4／7 は 20／37／54 秒です。無効時は基本時間で固定します。
  • 最初の一致のみを使い、一致しなければ接続全体が無効になります。距離・運賃・方向は変更しません。エディターの [] は条件を削除しますが、路網 JSON の variants: [] は接続を無効にします。
  • 旧斜率は読み込みできますが、エクスポートでは接続の真偽値設定と共通式に変換します。基本時間の編集だけでは既存の条件式基本時間は更新しません。
[
  {
    "when": {
      "enableExpressCarts": [
        1,
        2,
        3
      ]
    },
    "timeSec": 52.5,
    "reverseTimeSec": 52.5
  }
]

公式運賃設定（JSON） · fares (ja)

運賃表だけでなく運賃設定全体の JSON オブジェクトです。type は無料・区間加算・出発到着駅別、currency は通貨、matrix は駅間運賃、externalTransfers は改札外乗換の規則です。詳細と例は説明文書をご覧ください。

  • type は free（無料）、additive（区間の metrics.price を加算）、origin-destination（matrix[出発駅ID][到着駅ID] の運賃）です。currency は文字列または null。運賃表示は UI 設定で別に制御します。
  • matrix は canonical 駅 ID をキーとする入れ子のオブジェクトで、運賃は非負有限数です。正逆方向を別々に入力します。同一駅は 0、該当する駅間データがなければ運賃は不明です。
  • 任意の externalTransfers は from、to、maxSeconds で改札外乗換の割引時間上限を指定します。超過すると origin-destination 運賃を区間ごとに計算します。規則は双方向に適用します。
  • ticketType、source、download、retrieved、transferSource は券種・出典の情報です。例は構造の説明用で、駅 A・B は地図に存在する必要があります。maxSeconds は割引の上限で、徒歩所要時間ではありません。
{
  "type": "origin-destination",
  "currency": "TWD",
  "matrix": {
    "A": {
      "A": 0,
      "B": 20
    },
    "B": {
      "A": 20,
      "B": 0
    }
  },
  "externalTransfers": [
    {
      "from": "A",
      "to": "B",
      "maxSeconds": 1200
    }
  ]
}

その他の経路設定 · options (ja)

経路の優先条件、乗換係数、馬の速度、快速トロッコのレベルを設定する JSON オブジェクトです。defaults は初期値、comparators は比較順序と重みです。初期値は対応する選択肢リストに含めてください。詳細と例は説明文書をご覧ください。

  • defaults は criteria、transferCoef を指定し、対応リストがある場合は horseSpeedClass、enableExpressCarts も設定します。criteria は優先条件コード、transferCoefficients は 1 以上の有限な選択可能係数です。初期値は対応リストに含めます。
  • 任意の horseSpeeds は文字列コード、expressLevels は数値レベルのリストです。variants.when と組み合わせます。選択肢の追加だけでは接続や時間は生成されません。
  • comparators は優先条件コードと重みオブジェクトの配列を対応させます。各オブジェクトの加重合計を配列順に比較し、同点のときだけ次を比較します。小さい値が優先されます。
  • 重みのキーは timeSec、transfers、transferTimeSec、stops のみです。重みは非負有限数で、各組に正の重みが必要です。各優先条件に comparator を用意します。例は時間を優先し、同時間なら乗換回数を比較します。
{
  "defaults": {
    "criteria": "time",
    "transferCoef": 1
  },
  "criteria": [
    "time",
    "transfers"
  ],
  "transferCoefficients": [
    1,
    4,
    7
  ],
  "comparators": {
    "time": [
      {
        "timeSec": 1
      },
      {
        "transfers": 1
      }
    ],
    "transfers": [
      {
        "transfers": 1
      },
      {
        "timeSec": 1
      }
    ]
  }
}
